# 저작권 규칙

## 글
- 출처 문장을 그대로 옮기지 않는다. 내용을 이해하고 자기 문장으로 다시 쓴다.
- 직접 인용이 꼭 필요하면 한 출처당 1회, 15단어(어절) 미만, 따옴표와 출처 표시.
- 기사 구조(소제목 순서·흐름)를 그대로 따라 쓰지 않는다.
- 공공기관 자료도 문장 복사 대신 요약하고 출처를 단다.

## 이미지·영상 (Phase 3에서 적용)
- 사용 가능: 직접 제작 인포그래픽·차트, 상업적 이용이 명시된 스톡(Pexels, Unsplash, Pixabay), 라이선스가 명확한 Wikimedia Commons.
- 금지: Google/네이버 이미지 검색 결과, 뉴스 사진, SNS 사진, 라이선스 불명 이미지, YouTube 영상 다운로드.
- 모든 이미지는 manifest에 출처·작가·라이선스·확인일·Alt를 기록. `licenseVerified !== true`면 발행 제외.
- 정부 로고·기관 CI·인물 사진은 쓰지 않는다.
