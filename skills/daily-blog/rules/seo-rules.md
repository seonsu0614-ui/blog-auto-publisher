# SEO 규칙 (검색엔진을 속이지 않는다)

| 항목 | 기준 |
|---|---|
| 제목 | 15~60자, 핵심 키워드 앞쪽, 숫자·연도로 구체화, 낚시 금지 |
| SEO 제목 | 검색 결과용, 제목과 의미 동일 |
| 메타 설명 | 50~160자, 글이 답하는 질문 + 기준일 |
| 핵심 키워드 | 본문 2~12회, 자연스럽게. 도배 금지 |
| 보조 키워드 | 2~5개, H2·FAQ에 자연스럽게 |
| 구조 | H1=게시물 제목(테마), 본문 H2 3개 이상, 필요 시 H3 |
| FAQ | 2~4개, 실제 검색 질문 형태("~하면 ~되나요?") |
| 이미지 Alt | 이미지 실제 내용 설명. 키워드 반복 금지 |
| 내부 링크 | 관련도 있는 기존 글만(중복검사의 internalLinkCandidates). 없으면 억지로 넣지 않음 |
| 외부 링크 | 공식 출처 원문 링크 |
| 태그 | 3~15개, 카테고리 + 핵심·보조 키워드 |

좋은 제목 예: "2026년 자동차세 연납 신청 기간과 할인율 정리", "기준금리가 바뀌면 내 대출이자는 얼마나 달라질까"
나쁜 제목 예: "충격적인 소식!!!", "이걸 모르면 큰일납니다", "정부가 드디어 발표했습니다!!!"
