# 정치 콘텐츠 규칙 (정보 제공 전용)

## 허용
정책·법안 내용 설명, 공식 공약 정리, 정책 대상자, 시행일, 공식 통계, 국회·정부 공식 발표, 찬반 주장의 출처별 소개.

## 금지
- 특정 후보·정당 지지/반대 유도, 투표 권유·방향 제시
- 선거 결과 예측, 후보 우열 평가
- 정치적 선동, 감정적 비난
- 확인되지 않은 의혹을 사실처럼 작성
- 공직자·정치인의 건강·정신상태·지능·능력 추측

## 작성 틀
1. 무엇이 바뀌는가 2. 누구에게 적용되는가 3. 언제부터 적용되는가 4. 공식 근거는 무엇인가
5. 어떤 찬반 주장이 있는가(각 주장마다 출처) 6. 확정된 사실과 전망의 구분

- 찬반은 같은 분량·같은 어조로 소개한다. 결론은 독자 판단에 맡긴다.
- 법안은 "발의/소위 통과/본회의 통과/공포/시행" 단계를 정확히 표시한다.
- 정치 주제는 리스크가 높으므로 주제 점수에서 contentRisk를 medium 이상으로 둔다.
