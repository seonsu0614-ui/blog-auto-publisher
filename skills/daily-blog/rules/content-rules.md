# 콘텐츠 규칙

## 쓰지 않는 것
- 확인되지 않은 사실, 출처 없는 숫자
- 낚시·공포·과장: 무조건, 100% 확정/보장, 충격, 정부가 숨기는, 큰일납니다, 반드시 폭등/폭락, 돈 번다, !!!
- AI 상투구: "안녕하세요 여러분", "오늘은 ~에 대해 알아보겠습니다", "좋아요와 구독 부탁드립니다"
- 글자 수를 채우기 위한 반복 문장, 본문과 관계없는 인기 키워드
- 특정 금융상품 가입 권유, 투자 수익 보장

## 쓰는 방식
- 첫 문장부터 본론. Hook 2~5문장은 독자의 실제 상황(얼마를 더 내나, 언제까지 신청하나)에서 시작하고, 본문 핵심 정보와 반드시 연결한다.
- 문단은 2~4줄. 숫자는 표로, 절차는 번호 목록으로.
- 전문용어는 처음 나올 때 한 줄로 풀어 쓴다. 예: DSR(총부채원리금상환비율, 연소득 대비 모든 대출의 원리금 비율)
- "~할 수 있습니다", "~로 발표했습니다"처럼 근거 수준에 맞춘 표현을 쓴다. 단정은 공식 확정 사항에만.
- 과거 정보와 현재 정보를 구분한다: "2025년에는 ~였고, 2026년 10월 현재 ~입니다".

## 기본 구조
1. Hook → 2. 핵심 요약(기준일 표시) → 3. 왜 지금 알아야 하나 → 4. 핵심 내용 → 5. 내 생활에 어떤 영향 / 숫자로 보면(표·계산) → 6. 실제로 확인해야 할 사항 / 주의할 점 → 7. FAQ → 8. 핵심 정리 → 9. 출처(자동)
