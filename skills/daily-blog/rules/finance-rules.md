# 금융·경제 콘텐츠 규칙

## 숫자는 전부 근거를 남긴다
금리, 금액, 비율, 기간, 날짜, 세율, 한도, 지원금, 대출조건, 통계 → 모두 Claim으로 등록.

| 필드 | 예 |
|---|---|
| value | 2.50% |
| referenceDate | 2026-08-28 |
| condition | 한국은행 기준금리, 금통위 결정일 기준 |
| sourceIds | S1(한국은행 보도자료), S2(언론 보도) |

## 계산
- 계산 예시는 formula에 식을 적는다: `100000000 * 0.04 * 1` → value `4,000,000원`
- 예시용 가정값(원금 1억 원, 금리 4% 등)은 "가정"이라고 본문에 명시하고 Claim에 `notes: "계산 예시용 가정"`.
- 원리금균등·원금균등 등 복잡한 계산은 단순화했다면 "단리 기준 단순 계산"처럼 한계를 밝힌다.

## 최신성
- 공식 자료의 기준일을 반드시 확인. 지난해 자료를 올해처럼 쓰지 않는다.
- 금융상품 조건(금리·한도)은 수시로 바뀌므로 "OO일 공시 기준"을 붙이고, 확인처(금융감독원 금융상품통합비교공시 등)를 안내한다.

## 금지
- 특정 상품·금융회사 추천, "지금 사야/갈아타야 한다" 같은 개인 맞춤 조언
- 투자 수익률 전망을 사실처럼 쓰기
- 대출 승인 가능성 단정 ("누구나 대출된다")
