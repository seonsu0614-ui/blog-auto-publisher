# 팩트체크 프롬프트

원고에 들어갈 사실을 하나씩 Claim으로 만든다.

체크리스트
- [ ] 날짜: 시행일·신청 기간·발표일이 출처 원문과 일치
- [ ] 숫자·금액·비율: 단위(%, %p, 원, 만 원)까지 일치
- [ ] 계산: formula 기록, 코드가 재계산
- [ ] 정책 내용: 확정(공포·시행)인지, 예정·검토 중인지 구분
- [ ] 인용: 15어절 미만, 출처당 1회
- [ ] 출처: 모든 Claim에 sourceIds, 1순위 공식 출처 최소 1개
- [ ] 현재 적용 여부: 기준일이 오늘 기준으로 유효한지
- [ ] 과거·현재 구분: 이전 제도와 바뀐 제도를 섞지 않음
- [ ] 출처 간 충돌: 있으면 conflict=true → REVIEW_REQUIRED

verified=true 조건: 1순위 출처 원문에서 직접 확인했거나, 2개 이상의 독립 출처가 같은 값을 말함.
그 외에는 verified=false로 두고 본문에서 그 값을 쓰지 않는다.
