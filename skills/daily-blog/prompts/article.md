# 원고 작성 프롬프트

입력: 확정된 주제, 출처 목록, 검증된 Claim 목록
출력: ArticleDraft JSON (src/types/draft.ts)

- Hook 2~5문장: 독자 상황에서 시작 → 이 글이 답할 질문으로 연결. 공포 조장 금지.
- summary 3~5개: 기준일과 핵심 숫자. 숫자 문장 끝에 {C번호}.
- sections: content-rules.md의 기본 구조. H2 4~6개, 필요하면 H3.
- "숫자로 보면" 섹션: 표 1개 이상 + 계산 예시(formula Claim 연결).
- "실제로 확인해야 할 사항": 신청처·확인처를 기관명으로 안내(공식 URL은 출처로).
- FAQ 2~4개: 실제 검색 질문 형태. 답은 2~3문장.
- closing 3~5개: 행동 가능한 정리(언제까지, 어디서, 무엇을 확인).
- image slot 5~8개를 섹션 사이에 분산, video slot 1개는 핵심 요약 뒤.
- 공백 제외 2,000~3,000자. 짧으면 사례·조건 설명을 보강하고, 같은 말 반복으로 채우지 않는다.
