# 리서치 프롬프트

주제: {TOPIC} / 핵심 키워드: {KEYWORD}

1. 공식 1차 출처를 먼저 찾는다: 부처 보도자료, 공고문, 법령(국가법령정보센터), 기관 안내 페이지.
2. WebFetch로 원문을 열어 다음을 메모한다: 시행일, 대상, 금액·비율, 신청 방법, 예외 조건, 자료 기준일.
3. 같은 사실을 다른 독립 출처(다른 기관 또는 신뢰 언론) 1곳 이상과 대조한다.
4. 값이 다르면 둘 다 기록하고 충돌로 표시한다. 더 최신·더 공식적인 쪽을 본문에 쓰되 충돌이 해소되지 않으면 발행하지 않는다.
5. 출처마다 DraftSource 기록: { id, title, url, publisher, tier, accessedAt, referenceDate }
6. 뉴스는 보조 자료. 뉴스에만 있는 숫자는 공식 자료로 다시 확인하기 전까지 쓰지 않는다.
7. 원문 문장을 복사하지 않는다(메모는 요약으로).
