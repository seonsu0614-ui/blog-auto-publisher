# 영상 프롬프트

`media.video`에 VideoSpec으로 작성. 코드가 1080×1920 H.264 MP4(무음, 10~30초)로 만든다.

| 장면 kind | 기본 길이 | 내용 |
|---|---|---|
| hook | 3.5초 | 질문형 한 문장 (0~3초) |
| fact | 6초 | heading + big(핵심 숫자) + body(근거) |
| explain | 5.5초 | 설명 1~2개 장면 |
| cta | 4초 | "자세한 내용은 본문에서" + 다음 일정 |

- 장면 4~6개, 전체 10~30초 (seconds로 조정 가능). 범위를 벗어나면 생성 거부.
- big에는 검증된 숫자만, {C번호} 필수.
- 외부 영상·음원(YouTube 등) 사용 금지.
