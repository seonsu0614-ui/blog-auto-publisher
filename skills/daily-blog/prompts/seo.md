# SEO 프롬프트

원고를 바탕으로 다음을 채운다(본문 내용을 바꾸지 않는다).
- title: 15~60자, 핵심 키워드 포함, 연도·숫자로 구체화
- seoTitle: 검색 결과용 짧은 제목
- metaDescription: 50~160자, "무엇을/누가/언제" + 기준일
- primaryKeyword 1개, secondaryKeywords 2~5개, relatedKeywords 3~8개
- tags 3~15개: 카테고리 + 키워드
- slug(선택): 영문 소문자-하이픈. 예: car-tax-annual-payment-2026
- 이미지 Alt는 Phase 3에서 이미지 실제 내용 기준으로 작성
- 내부 링크: 중복검사 결과의 internalLinkCandidates 중 관련 있는 것만 본문 자연스러운 위치에
